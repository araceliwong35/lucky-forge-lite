# lucky-forge-lite

Observability · Rust · Compilers

留着备查的示例

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/lucky-forge-lite.git
cd lucky-forge-lite
cargo build --release
```
